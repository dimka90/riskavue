# Riskavue — Your limits. In sight.

**Main track:** Exchanges & Stocks (Binance Futures Demo).  
**Special award:** Best Telegram integration.  
**Repository:** https://github.com/dimka90/riskavue

## Description

Riskavue helps traders follow their own loss limits when a trading session gets emotional. On Even G2, one glance shows the remaining distance to the account's loss floor. Voice creates a proposed action; a tap confirms it. The backend checks the rules again before sending an order.

A session lock blocks new entries through Riskavue until the displayed reset time, cancels pending entries, and preserves protective stops. It survives restarts and cannot be undone with a tap. Telegram provides the same status and confirmation flow when the glasses app is not active. Claude produces a short review grounded in the recorded session.

The integration uses Binance Futures Demo only, with fake funds. Paper scenarios are labelled. Riskavue cannot block trades placed directly on Binance; it can observe them and offer corrective actions. Missing stops and stale data block new Riskavue entries.

## Demo sequence

3. Confirm an action using simulator touch input.
4. Trigger a paper session lock; show its deadline and preserved protective stops.

## Existing dependencies

The project uses existing open-source libraries and services, including the Even Hub SDK and official simulator, Node.js, TypeScript, Vite, Express, grammY, SQLite, Binance Futures Demo, Deepgram, and Anthropic. Versions are recorded in the lockfile. Implementation started on November 24 during the hackathon, with Codex assistance. The bridge follows the official Even Hub minimal example. No cc-g2 or unlicensed competitor code was copied; see the README provenance disclosure.
